Privacy Policy

Last updated: 31 October 2026

Creator Desk ("the app") is a private tool used only by its owner to manage the owner's own YouTube channels. This policy explains what data the app accesses and how it is used.

Creator Desk uses YouTube API Services. By using it you also agree to be bound by the YouTube Terms of Service, and you can read the Google Privacy Policy to see how Google handles data.

Data the app accesses

When the owner signs in with Google, the app can access, for the owner's own channels only:

  • YouTube account and channel information, to identify which channel is being managed.
  • Permission to upload videos, thumbnails, captions and metadata (YouTube Data API).
  • YouTube Analytics reports for the owner's own videos, such as views, watch time and audience retention (YouTube Analytics API).

How the data is used

The data is used only to publish the owner's videos and to show the owner how those videos are performing so the owner can improve future videos. It is not used for advertising, profiling or any other purpose.

Storage and sharing

Sign-in tokens and analytics results are stored only on the owner's own computer. The app does not sell, share or transfer this data to any third party, and it does not collect data from any other person.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

The only data kept is the sign-in tokens and analytics results for the owner's own channels, stored on the owner's computer. This data is deleted when access is revoked, when it is no longer needed, or on request. No YouTube data is stored anywhere else.

Your control

The owner can revoke the app's access to their data at any time in the Google security settings (also reachable at myaccount.google.com/permissions) and can delete the locally stored tokens at any time.

Changes and contact

If this policy changes, this page will be updated. Questions: see the owner's GitHub profile.
